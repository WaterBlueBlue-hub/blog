# Texture
## Texture2D
&emsp;&emsp;它代表一张普通的图片。   
## RenderTexture
&emsp;&emsp;这是一种特殊的动态纹理，不在硬盘上保存，而是直接在显存中由摄像机（Camera）或计算着色器（Compute Shader）实时渲染输出的目标。
## Texture3D
&emsp;&emsp;体积纹理。它是一个 3D 的像素阵列。常用于体积雾、3D 噪声等。
