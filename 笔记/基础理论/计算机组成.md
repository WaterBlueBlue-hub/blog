# 计算机组成
## 内存与缓存
&emsp;&emsp;内存（RAM）和缓存（Cache）本质上都是计算机中用于临时存放数据的存储介质。  
&emsp;&emsp;内存是计算机的主工作区，负责临时存放操作系统和当前所有运行中程序的全部数据。它的容量大，是硬盘与 CPU 之间必经的数据桥梁，但其读取速度远远跟不上现代 CPU 的计算速度，构成了限制系统整体性能的内存墙。  
&emsp;&emsp;缓存直接镶嵌在 CPU 内部，专为打破内存速度瓶颈而生。它造价昂贵且容量极小，利用数据访问的局部性原理，精准囤积 CPU 马上要频繁用到的热点数据与指令，用极小的空间换取了与 CPU 计算几乎同步的极致速度。  
## 托管与非托管
&emsp;&emsp;托管指程序的执行与底层资源（尤其是内存）完全由特定的运行时环境（如 .NET CLR 或 JVM）自动统一管理，程序员只需声明和申请所需内存，系统后台的垃圾回收器（GC）会自动追踪其使用状态，并在不再被引用时自动执行清理与释放，从而保证内存安全并防止泄漏。  
&emsp;&emsp;非托管指越过运行时环境，直接调用操作系统底层接口申请和操作的内存与系统级资源（如文件句柄、底层图形接口或 C/C++ 指针），这部分资源完全不受垃圾回收机制的监控，要求程序员必须在代码中显式实现资源的分配与精准的手动释放，任何遗漏都会直接导致内存泄漏。
