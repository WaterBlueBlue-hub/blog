# 操作系统
## 线程与进程
&emsp;&emsp;线程是操作系统调度的基本单位，指一段可以独立跑起来的执行流。  
&emsp;&emsp;程序本身只是一堆指令和数据。CPU 执行它的时候，靠一个叫程序计数器的寄存器记住下一条指令在哪里。除了它，还要用一批寄存器算数、用一个调用栈记录函数调用到了哪一层、局部变量放在哪。  
&emsp;&emsp;程序计数器 + 寄存器状态 + 一个栈就是一个执行流。CPU 沿着它往下走。  
&emsp;&emsp;进程是一份地址空间 + 至少一条执行流。线程是那份地址空间里的一条独立执行流。  
&emsp;&emsp;同一个进程里的多条线程共享同一份地址空间，但各自有私有的栈和寄存器状态。
## 多线程
&emsp;&emsp;物理上，一个 CPU 核心在同一时刻只能执行一条指令流。所以当线程数超过核心数时，操作系统给每条线程分配一个时间片，跑完就换下一条，这叫时间片轮转。

## 并发与并行
&emsp;&emsp;并发是指多条执行流交替推进，宏观上看起来是同时发生，单核用时间片就能做到。  
&emsp;&emsp;并行是指多条执行流真的在同一时刻各自推进，必须有多个核心。
