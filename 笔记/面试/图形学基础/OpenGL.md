# OpenGL
## OpenGL和别的 API 比，有什么优缺点？
&emsp;&emsp;OpenGL 的优势在于极高的跨平台兼容性，其缺点是设计理念落后于现代 GPU 架构，厚重的驱动层会导致极高的 CPU 额外开销，且全局状态的特性使其难以实现高效的多线程渲染调度，这也是为什么现代游戏引擎正全面转向能将底层显存与管线控制权直接交给开发者、完美契合多核并行的现代低开销 API（如 Vulkan、DirectX 等）。
