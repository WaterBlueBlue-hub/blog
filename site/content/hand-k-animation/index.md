# 手 K 动画
## 简介
&emsp;&emsp;本作品整理了一些手 k 的待机、跑步、单击、连击动作素材，以正视图和侧视图记录，并合成为展示片。

## 作品概览
| 作品 | 内容 |
| --- | --- |
| 作品类型 | 手 K 动作展示、正侧视图动作对照 |
| 角色 | 刃、胡桃、安比、忌炎 |
| 动作 | 待机、跑步、单击、连击 |
| 素材规格 | 10 段动作展示视频，每组正视图与侧视图等长 |
| 成片规格 | 1920 × 1080、60fps、55.65 秒、无音轨 |
